# Aruna DSS V4 — Blue Orange Final UI

Versi ini mempertahankan logic optimizer V3, tetapi UI dibuat lebih besar, lebih sederhana, lebih interaktif, dan mengikuti identitas biru–orange Aruna.

## Menu utama
1. **Pusat Kendali** — kondisi shipment + sinyal operasional.
2. **Studio Keputusan** — area input utama dan tombol Hitung Rekomendasi.
3. **Rencana Produksi** — rekomendasi produksi per SKU + alasan + approval.
4. **Dampak Keputusan** — bandingkan Nilai Maksimum, Kurangi Excess, dan Efisiensi Energi.
5. **Data & Model** — sumber data dan asumsi yang perlu validasi.

## Cara pakai
Klik `run_windows.bat`, buka `http://localhost:8501`, lalu masuk ke **Studio Keputusan**.
